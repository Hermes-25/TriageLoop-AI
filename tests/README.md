# Verification Boundary

Planned suites:

- `unit/` - clinical rules, formulas, model utilities, windows and audit integrity.
- `contract/` - JSON Schema and API compatibility.
- `scenarios/` - required patient/problem-statement behaviours.
- `simulation/` - policy comparison and seeded reproducibility.
- `e2e/` - browser hero, surge, override and audit paths.
- `safety/` - Safe Mode and no-autonomous-downgrade invariants.

Test identifiers and required evidence are predeclared in `docs/requirements-traceability.md`.
